# Desafio Ransomware - Santander Bootcamp Cibersegurança

Este projeto foi desenvolvido como parte do **Santander Bootcamp de Cibersegurança** em parceria com a [DIO](https://www.dio.me). O objetivo foi criar uma simulação simples de ransomware para demonstrar os conceitos de criptografia e como arquivos podem ser protegidos ou comprometidos em um ambiente controlado.

## Sobre o Projeto

O projeto consiste em uma implementação básica de ransomware, onde:
- Um arquivo é criptografado utilizando um script Python.
- O mesmo arquivo pode ser descriptografado e restaurado ao formato original.

**⚠️ Aviso:** Este projeto foi criado apenas para fins educacionais e deve ser utilizado exclusivamente em um ambiente controlado. Não use este código em sistemas de produção ou para atividades maliciosas.

---

## Arquivos do Projeto

O repositório contém os seguintes arquivos:

1. **`teste.txt`**
   - Arquivo de texto simples que será utilizado como exemplo para a criptografia e descriptografia.

2. **`encrypter.py`**
   - Script responsável por criptografar o arquivo `teste.txt`, alterando seu conteúdo e renomeando-o para `teste.txt.ransomwaretroll`.

3. **`decrypter.py`**
   - Script para reverter a criptografia, restaurando o conteúdo original do arquivo e seu nome para `teste.txt`.
